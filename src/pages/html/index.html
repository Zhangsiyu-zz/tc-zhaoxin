ABOUT THE LAB

实验室介绍

TC 实验室成立于 2015 年，始终坚持以项目为导向：从选题、设计、开发到交付，成员在完整周期中训练工程能力与协作意识。

我们面向真实需求做产品与竞赛，强调可运行、可演示、可迭代。无论你来自哪个年级，只要愿意动手、愿意把事情做完，这里都欢迎你。

  • 以项目为载体，在实践中学习技术栈与工程规范。
  • 四个方向协同：嵌入式、前端、后端、安卓，组队完成完整作品。
  • 鼓励参赛与作品沉淀，把过程变成可展示的成果。
FOUR TRACKS

四大方向

选择一条主线深入，同时在项目中与其他方向协作。报名时可选择意向方向。

嵌入式

面向单片机、传感器与实时系统，完成从电路到固件的整机开发，适合喜欢“让设备真正跑起来”的同学。

Hardware / Firmware

前端

负责界面、交互与工程化体验，把实验室作品做成干净、现代、可访问的产品页面。

UI / Engineering

后端

搭建接口、数据与权限体系，让报名、面试与项目系统稳定运转，训练服务端设计能力。

API / Architecture

安卓

开发移动端应用与实验室工具，关注性能、适配与产品细节，把能力送到用户口袋里。

Mobile / Product
